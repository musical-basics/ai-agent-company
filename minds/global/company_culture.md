# 🏢 Company Culture — {{company_name}}

> **Version**: 1.0 | **Last Updated**: {{last_updated}}

## Core Values

1. **Process Over Patch**: Never apply a one-off fix. Always fix the underlying process so the issue never recurs.
2. **Glass Box Transparency**: Every action produces a traceable artifact. No black boxes.
3. **Adversarial Quality**: Departments challenge each other. Friction is a feature, not a bug.
4. **Budget Discipline**: Every API call costs money. Optimize for efficiency.
5. **Evolutionary Growth**: The company gets smarter every day through hardened SOPs.

## Communication Rules

- All inter-department communication happens via **structured JSON artifacts** on the Event Bus.
- No free-form chatting between agents. Every message must have a schema.
- Rejections are data, not insults. Always include actionable feedback.

## Risk Tolerance

- **Default**: Medium. Follow SOPs strictly. Escalate edge cases.
- The CEO may temporarily adjust per-department risk tolerance via directives.
